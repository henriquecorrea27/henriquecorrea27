## Sobre mim

Analista de Sistemas Júnior na **TCS**, em projeto para o setor bancário, onde trabalho com **Python e AWS** (Glue, Lambda, Athena e S3). Sou bacharel em **Ciência da Computação** pela Unifil (Londrina/PR) e tenho experiência com Machine Learning desde o estágio.

Fora do trabalho, construo aplicações completas com **programação assistida por IA** (Claude e GitHub Copilot). Busco oportunidades de desenvolvimento com foco em **soluções com IA**.
